# Job Portal / Internship Finder System

## Overview
A full-stack web application that connects students with recruiters for internships and jobs.

## Roles
- Student: register/login, create profile, upload resume, browse jobs, apply, track applications
- Recruiter: post jobs, manage job listings, view applicants, update application status
- Admin (optional): manage users and jobs

## Tech Stack
- Frontend: HTML5, CSS3, Bootstrap, JavaScript, jQuery, AngularJS, React
- Backend: Node.js, Express.js
- Database: MongoDB (Mongoose)
- Communication: REST APIs, JSON, AJAX

## Folder Structure
- server/         -> Backend (Node + Express)
- client-static/  -> HTML/CSS/Bootstrap/JS/jQuery UI
- client-angular/ -> AngularJS SPA
- client-react/   -> React SPA
- docs/           -> Report assets (screenshots/diagrams)

## Features (Planned)
- Authentication (sessions + cookies)
- Job CRUD (recruiter)
- Apply to jobs (student)
- Application tracking + status update
- Email notification on apply (optional)
